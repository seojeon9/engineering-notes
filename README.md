# Engineering Notes

> 어떤 문제를 어떻게 해결했는지 기록합니다.

이 저장소는 기술을 공부한 내용을 정리하는 공간이 아닙니다.

실제 개발 및 운영 과정에서 경험한 문제를 분석하고,
해결 과정과 의사결정을 기록하기 위한 개인 Engineering Notes입니다.

## 다루는 주제

- Airflow
- Kubernetes
- PostgreSQL
- Snowflake
- Docker
- Linux
- AWS
- AI Agent

## 기록 원칙

- 기술보다 문제를 기록합니다.
- 해결 과정과 의사결정을 기록합니다.
- 같은 주제는 하나의 문서로 계속 발전시킵니다.
